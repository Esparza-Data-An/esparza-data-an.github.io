# 📊 Videogame Analysis

## Descripción del Proyecto

Análisis exploratorio de datos de videojuegos para identificar **patrones que determinen el éxito de un juego**. El estudio utiliza datos de más de 16,000 videojuegos, enfocándose en la era moderna de consolas (desde 2005 en adelante) para garantizar datos significativos con scores de críticos y usuarios.

## 🎯 Objetivos

1. **Identificar patrones de éxito** - Factores que correlacionan con altas ventas
2. **Analizar tendencias por plataforma** - Qué consolas dominaron cada período
3. **Estudiar géneros y ratings** - Preferencias por región geográfica
4. **Validar hipótesis** - Mediante pruebas estadísticas rigurosas

## 📈 Metodología

### Fases del análisis:

- **Preparación de datos**: Limpieza de valores nulos, normalización de formatos, conversión de tipos
- **Análisis exploratorio**: Distribuciones, correlaciones, tendencias temporales
- **Segmentación regional**: Perfiles por región (Norteamérica, Europa, Japón, otros)
- **Visualizaciones**: Gráficos de tendencias, scatter plots, distribuciones
- **Pruebas de hipótesis**: Validación estadística de patrones identificados

## 🛠️ Tecnologías Utilizadas

- **Python** - Análisis principal
- **Pandas** - Manipulación y transformación de datos
- **NumPy** - Operaciones numéricas
- **Matplotlib & Seaborn** - Visualizaciones
- **SciPy** - Pruebas estadísticas

## 📊 Dataset

- **Fuente**: 16,000+ videojuegos
- **Período analizado**: 2005 - 2016
- **Variables principales**:
  - Año de lanzamiento
  - Plataforma (consola)
  - Género
  - Clasificación (Rating)
  - Ventas por región (NA, EU, JP, Otros)
  - Scores de críticos y usuarios

## 🔍 Hallazgos Clave (Resumen)

El análisis incluye:
- Tendencias de ventas por año y plataforma
- Relación entre ratings y ventas
- Diferencias de preferencias por región
- Ciclo de vida de las consolas
